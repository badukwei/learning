# 求職投遞策略

更新：2026-07-01

## 核心結論

現階段第一目標是取得面試邀約，不是直接最佳化 offer、薪資或理想工作條件。

因此不走純海投，也不走超精細少量投遞；同時不再把 `$70k+` 當成唯一可接受結果。

採用策略：

**A 精投 + B 半客製化大量投遞 + C 快速補量**

## 當前北極星指標

2026-07 的北極星指標：`面試邀約數`

短期判斷標準：

- `20` 份投遞內至少要出現 recruiter 回覆或初步面試。
- 如果 `20` 份後完全沒有回覆，先調整履歷定位與投遞類型，不先怪自己能力不足。
- 如果有回覆但沒有進面試，調整 opener、履歷 summary、職缺匹配敘事。
- 如果有面試但沒後續，才把重點轉向面試表現與技術補強。

## 2026-07 策略調整

目前市場條件偏硬，若同時要求：

- 全遠端 / worldwide remote
- UTC+8 友善或 async-first
- `$70k+ USD`
- Frontend / Product Engineer
- 文化與 WLB 風險低

可投職缺會太少，容易造成投遞量不足與心理壓力過高。

新的策略不是放棄高薪目標，而是改成海外三層 offer strategy，加上一條台灣學習型正職路線：

| 層級 | 目標 | 薪資區間 | 目的 |
|---|---|---:|---|
| A | 理想 offer | `$70k+ USD` | 繼續精投，但不把它當作唯一成功標準 |
| B | 可接受正職 offer | `$50k-70k USD` | 主要轉換目標，先取得海外遠端正職經驗 |
| C | 過渡合約 / 現金流 | `$30-50/hour` 或 `$40k-60k USD` | 降低空窗壓力，同時保留繼續面試的彈性 |
| T | 台灣學習型正職 | 可接受降薪 | 補強工程深度、產品經驗、團隊協作與下一輪跳槽籌碼 |

## 新投遞原則

- `A 級`：高薪、全球遠端、技術與敘事高度匹配；每週少量精投。
- `B 級`：薪資不一定到 `$70k`，但能提供海外遠端履歷與穩定現金流；作為主力投遞。
- `C 級`：合約、AI coding evaluation、短期 remote frontend/fullstack；只作為過渡，不停止正職求職。
- `T 級`：台灣本土職缺，可以接受薪水降低，但必須明確能學到東西，且不能只是消耗型開發。

每週投遞配比暫定：

- `A 級`：2-3 份
- `B 級`：8-12 份
- `C 級`：3-5 份
- `T 級`：3-5 份，優先找高學習密度團隊

在拿到穩定面試前，職缺篩選標準要比之前寬：

- 只要技術棧、年資、地點或遠端條件大致符合，就可以投。
- 薪資未知可以投，等 recruiter screen 再確認。
- 職缺不是完美匹配也可以投，目的是取得市場回饋與面試練習。
- 明顯不符合地區、簽證、語言、年資差距太大的才排除。

## 薪資底線

- `$70k+ USD`：仍是談判目標，不刪除。
- `$50k+ USD`：正職主要底線。
- `$40k-50k USD`：只有在職位能明顯累積海外遠端履歷、面試管線不足、或空窗壓力升高時才考慮。
- 低於 `$40k USD`：原則上不接受，除非是短期合約、工時低、且能保留主要求職時間。
- 台灣本土：可以接受薪資低於海外目標，但必須換到明確學習價值；如果薪水降低又沒有工程成長，不列入。

## 台灣本土職缺篩選標準

台灣職缺不是退路，而是學習跳板。只投符合以下條件的職缺：

- 有資深工程師或技術主管可以 code review / system design review。
- 工作內容能碰到 production scale，而不是只做切版、維護或短期外包。
- 技術棧能補強下一份海外工作的能力：React / TypeScript / Node.js / 系統設計 / AI product / devtools / fintech。
- 有明確產品 ownership，可以累積可量化成果。
- 團隊工程文化正常：測試、PR review、文件、部署流程至少有基本水準。

避免：

- 長工時、低薪、學不到東西的消耗型職缺。
- 純接案切版、沒有產品 ownership 的工作。
- 只需要照單完成需求、沒有技術討論與成長空間的團隊。

面試必問：

- 團隊如何做 code review？
- 這個職位前三個月會負責什麼功能或系統？
- 有沒有資深工程師能帶架構、效能、測試或系統設計？
- 最近半年團隊解過最有技術深度的問題是什麼？
- 這個職位的成功標準是什麼？

## 職缺範圍放寬

主力仍是 `Frontend Engineer`，但 2026-07 起可以更積極投：

- Product Engineer
- Fullstack Engineer（React / TypeScript / Node.js）
- Developer Tools / SDK Engineer
- AI coding evaluation / TypeScript reviewer contract

Web3 / DeFi 不作為唯一主線，但如果職缺是遠端且薪資合理，可以當作差異化機會。

## 追蹤指標

- 20 投後是否出現 recruiter screen 或面試邀約
- 被拒原因是否集中在地區 / seniority / 技能落差
- LinkedIn 接觸是否有回覆
- 哪類職缺最容易有正向訊號
- 每 20 份投遞檢查 A/B/C 哪一層最有回覆
- 台灣職缺要額外檢查是否真的能補強下一輪海外求職敘事
- 若 B/C 層也完全沒有 recruiter screen，優先調整履歷定位與 outreach，不先歸因為能力不足
