## 面試薪資問法

如果職缺寫 `待遇面議`，第一輪可以直接問：

> 想先確認這個職位的薪資區間大概落在哪裡？我目前主要看重學習密度與團隊成長性，但也希望確認雙方期待是否接近。

如果對方不願意說，可以追問：

> 那以 3 年以上 React / TypeScript / Fullstack 背景，這個職位通常會落在哪個職級或薪資 band？

## 面試評價確認問題

對 104 評價低或沒有公開分數的公司，優先問：

- 團隊如何做 code review？
- 最近半年工程團隊解過最有技術深度的問題是什麼？
- 前三個月我會負責新功能、重構、維護，還是客製需求？
- 一週大概有多少比例時間在開發、會議、維運、支援客戶？
- 是否有加班、on-call、緊急修 production 的常態？
