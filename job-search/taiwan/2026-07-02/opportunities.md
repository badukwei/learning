## A 級

### Taiwan AI Labs_雅婷智慧 — Senior Fullstack Engineer

- URL: https://www.104.com.tw/job/7lmrc
- 學習點：AI product、Node.js + TypeScript、React、Docker、Kubernetes、MySQL / MongoDB、network protocol、system design。
- 適合原因：最貼近「學到東西」目標，能補 fullstack、AI product、系統設計與英文工作環境。
- 風險：Senior title，英文要求高，可能面試門檻較硬。
- 建議：優先投，履歷強調 AI workflow、TypeScript SDK、安全監控、跨前後端交付。

### 網際威信 — AI 應用工程師

- URL: https://www.104.com.tw/job/8zdu6
- 學習點：FinTech、AI 大數據、資安、銀行系統、AI 開發工具流程、Docker / Kubernetes。
- 適合原因：你的 DeFi / security-first 背景可轉成金融科技與安控敘事。
- 風險：技術棧偏 Java/Spring/Angular，不是你最熟的 React 主線。
- 建議：優先投，當作 FinTech + AI + security 的台灣學習型路線。

### 安聯智能科技 — Software Engineer（React / React Native）

- URL: https://www.104.com.tw/job/938p1
- 學習點：SaaS、IoT、Mobile App、AI Product、React / React Native、產品需求討論、AI workflow。
- 適合原因：JD 明確說不只是寫功能，會參與產品設計、需求討論、使用者體驗與技術文件。
- 風險：小公司，需要確認 code review、架構成熟度與產品真實規模。
- 建議：優先投，這份很符合 Product Engineer 方向。
