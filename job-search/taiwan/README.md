# 台灣職缺紀錄

更新：2026-07-01

這裡記錄台灣本土學習型正職。

## 目前目標

- 第一目標：取得面試邀約。
- 可以接受薪水降低，但必須換到明確學習價值。
- 台灣職缺不是純退路，而是補強下一輪海外求職籌碼的學習跳板。

## 適合放這裡

- 台灣本土 Frontend / Fullstack / Product Engineer
- AI product、devtools、fintech、B2B SaaS、工程文化較好的產品團隊
- 有資深工程師 code review / system design review 的團隊
- 能碰 production scale、產品 ownership 或可量化成果的職缺

## 主要來源

- 104：台灣本土主來源，用來建立足夠面試樣本。
- Cake：台灣新創、英文職缺、遠端或 hybrid 機會。
- LinkedIn：補充來源與 networking，不做自動大量爬取。
- 公司官網：用來確認 JD 與投遞入口。
- Third-party APIs：只作為補助整理工具；台灣職缺仍以 104 / Cake / 公司官網確認為準。

## 不放這裡

- 純切版、純維護、短期外包
- 長工時、低薪、學不到東西的消耗型職缺
- 沒有 PR review、沒有技術討論、沒有產品 ownership 的團隊

## 批次格式

每次搜尋建立一個日期資料夾：

- `YYYY-MM-DD/README.md`
- `YYYY-MM-DD/leads.tsv`
- `YYYY-MM-DD/checklist.md`
- `YYYY-MM-DD/opportunities.md`

## 面試必問

- 團隊如何做 code review？
- 這個職位前三個月會負責什麼功能或系統？
- 有沒有資深工程師能帶架構、效能、測試或系統設計？
- 最近半年團隊解過最有技術深度的問題是什麼？
- 這個職位的成功標準是什麼？
