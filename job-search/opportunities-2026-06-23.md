# 可投遞職缺清單

更新：2026-06-23

篩選條件：

- 台灣可申請或明確標示 worldwide remote
- Frontend / Product / TypeScript 方向與目前背景有交集
- 薪資至少有機會達到 `US$70k`；若低於或不穩定會特別標示
- 將工作文化、WLB、管理風險與職缺穩定性納入評分
- 排除只有 US / Americas / EMEA、時區不符或公司文化風險過高的職缺

## 1. Buffer

📌 職位：[Senior Engineer - Growth Marketing](https://buffer.com/journey/a6615dc0-cc2d-4d80-905b-0b53d7b2dce6)

💰 薪資：`US$156,500–202,300` + equity

🌍 遠端：Worldwide remote

⭐ 評分：⭐⭐⭐⭐⭐（A，優先精投）

### 適合理由

- Next.js 15、React、TypeScript，技術棧直接符合。
- 需要 API integration、部分 backend logic、SEO、analytics 與 A/B testing。
- 明確重視 async communication、產品 ownership 與 AI 工具使用。
- 四天工作制、薪資透明、彈性休假，文化比 Binance 更符合目前優先條件。
- AI workflow、公開內容輸出與產品成果可作為差異化敘事。

### 主要缺口

- JD 傾向 `5+ years`，目前約 3+ 年，屬於 stretch application。
- Growth / SEO / experiment 經驗需要從既有產品、數據與內容工作中重新包裝。

### 履歷應強調

- React / TypeScript / Next.js 與產品功能端到端 ownership。
- `10,000+ users`、`$200M TVL` 等可量化產品規模。
- AI coding workflow 與公開內容輸出。
- 即時資料、效能、安全與第三方 API 整合。

## 2. Automattic

📌 職位：[Experienced Software Engineer](https://automattic.com/work-with-us/job/experienced-software-engineer)

💰 薪資：`US$70,000–170,000`，全球統一區間並以當地貨幣支付

🌍 遠端：Worldwide remote

⭐ 評分：⭐⭐⭐☆（B，可投但需盡職調查）

### 適合理由

- 全球分散式團隊，可從台灣工作。
- 主要使用 JavaScript 與 PHP，不要求申請前已是 PHP 專家。
- 重視 async written communication、open source、產品規模與 AI workflow。
- 全球薪資區間上限足以超過目標。

### 風險

- 2025 年曾裁員約 16%。
- 近期員工評價顯示 WLB 尚可，但管理層與職涯發展評分偏低。
- 職缺範圍較廣，最終分派產品與 frontend 比例需要在面試確認。

### 面試必問

- 會被分到哪個產品與團隊？JavaScript / frontend 的實際比例是多少？
- 該團隊過去 12 個月的人員流動與裁員情況？
- 台灣候選人的預期薪資區間？

## 3. G2i

📌 職位：[Software Engineer TypeScript (Remote)](https://jobs.ashbyhq.com/g2i/79c7146a-8b3d-47d2-8a80-f059e226103c/)

💰 薪資：`US$30–70/hour`，多數專案約 `US$30/hour`

🌍 遠端：Taiwan accepted

⭐ 評分：⭐⭐⭐（C，只適合作為過渡或兼職）

### 適合理由

- 要求 3+ 年 TypeScript，年資符合。
- 工作內容是審查、修正與解釋 AI 生成程式碼，符合 AI workflow 與 security-first 背景。
- Async、時間彈性，每週最低約 15 小時。

### 風險

- Independent contractor，沒有傳統正職福利。
- 工時依專案而定，不保證每週都有足夠工作量。
- 多數專案落在 `US$30/hour`，若以全職換算約 `US$62k/year`，低於目標。

### 建議用途

- 離職後的短期現金流。
- 補強 AI evaluation / RLHF 的履歷經驗。
- 不應停止正職求職，也不應作為唯一收入來源。

## 4. Canonical

📌 職位：[Web Frontend Engineer - JS, CSS, React, Flutter](https://job-boards.greenhouse.io/canonical/jobs/5150422)

💰 薪資：US entry-level 公開區間為 `US$48,000–70,000`；其他地區與職級另定

🌍 遠端：Worldwide remote

⭐ 評分：⭐⭐⭐（C，可投但薪資需先確認）

### 適合理由

- React / TypeScript、REST API、效能、安全與 accessibility 都符合。
- 全球遠端，明確接受不同國家的候選人。
- 重視文件、open source 與跨時區溝通。

### 風險

- 公開 entry-level 區間最高只有 `US$70k`，台灣 offer 可能低於目標。
- 招募流程非常重視高中、大學成績與書面回答。
- Flutter 與 Linux 經驗不是目前主力，需要說明學習能力。

### 建議

- 當作 B/C 類補量投遞，不投入大量客製化時間。
- Recruiter 初談時先確認台灣區間；低於 `US$50k` 直接退出。

## 暫不列入投遞

- `Binance`：技術匹配，但台北 WLB、文化與管理風險過高。
- `Parity Technologies`：技術匹配，但員工評價中的文化與管理風險偏高。
- `PostHog`：工程職缺時區限制為 GMT-8 至 GMT+2，不含台灣。
- `Tailscale`：目前官方聘僱國家集中於美國、加拿大、英國。
- `Mysten Labs / Phantom`：目前相關 frontend 職缺為 US-only。
- `DualEntry`：只接受 EU / LATAM。
- `GraphAware`：只接受 EU / UK。

## 值得持續監控但目前沒有可投職缺

- [Chess.com](https://www.chess.com/jobs)：員工評價的 WLB 與文化良好。
- [Toggl](https://toggl.com/jobs)：全球 remote、文化評價高，但目前官網沒有開放職缺。
- [Doist](https://doist.com/careers)：async-first、全球 remote、40 小時上限與 40 天 PTO，目前沒有工程職缺。
