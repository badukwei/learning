# 海外職缺紀錄

更新：2026-07-01

這裡記錄海外遠端、全球職缺、合約與 AI coding evaluation。

## 目前目標

- 第一目標：取得 recruiter 回覆與面試邀約。
- 薪資與理想條件先不過度篩選，等進 recruiter screen 再確認。
- 每 `20` 份投遞檢查一次回覆率。

## 適合放這裡

- Worldwide remote / async-first 職缺
- 接受台灣或 UTC+8 的海外公司
- 海外合約、短期專案、AI coding evaluation
- Frontend / Product / Fullstack / Developer Tools / SDK Engineer

## 主要來源

- 公司官網：最高品質，適合 A 級精投。
- LinkedIn：手動搜尋、saved search、networking，不做自動大量爬取。
- Cake：找亞洲 / 遠端 / 英文職缺。
- RemoteOK / Himalayas / Wellfound：海外遠端補量。
- Third-party APIs：可小量測試 Apify / SERP / job search API 來整理候選 lead，但投遞前仍要人工確認原始 JD。

## 批次格式

每次搜尋建立一個日期資料夾：

- `YYYY-MM-DD/README.md`
- `YYYY-MM-DD/leads.tsv`
- `YYYY-MM-DD/checklist.md`
- `YYYY-MM-DD/opportunities.md`

## 評估重點

- 是否接受台灣或 UTC+8
- 是否符合 React / TypeScript / Product / Fullstack / SDK 背景
- 是否能提高面試機率
- 薪資是否至少有機會接近 `$50k+ USD`，或能作為短期現金流
- 是否值得搭配 LinkedIn / direct contact
